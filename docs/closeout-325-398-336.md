# Closeout evidence: cf#325, cf#398, cf#336

Original defects are shipped on main. This page is the evidence disposition so the
issues can close without re-reading stale bodies.

## cf#325 -- container test suites run nowhere

**Original:** `ci.yml` pytest was scoped to `deploy/` only; `containers/**/test_*.py` never ran.

**Shipped:** PR #378 (`ci(containers): run the container test_*.py scripts nobody was running`).
`.github/workflows/ci.yml` has a dedicated container-tests job that lists and runs the
pytest-discoverable container suites and fails if zero tests are collected (the trap the
issue named). Remaining intentional skips (e.g. heavy local-only suites) are called out
in that workflow comment, not silent.

**Close when:** this disposition is accepted.

## cf#398 -- plane refusal read as pending forever

**Original:** all RunPod modules treated a failed poll (including plane-authored refusal) as
still-running `pending: true`.

**Shipped:** PR #402 (`fix(modules): surface a plane refusal on the poll path instead of pending`).
`planeRefusalReason` / `planeRefusalError` in `modules/_shared/runpod-route.ts`; every
RunPod-reaching module checks the plane-refusal header before interpreting status. Guarded
by `tests/plane-refusal-poll-cf398.test.ts`.

**Related residual:** cf#403 (header string dual-repo pin) is a separate control, not a reopen
of this defect.

**Close when:** this disposition is accepted.
